API Key (cho tính năng AI)

✕

Các tính năng AI dàn cảnh, dựng từ ảnh, tạo vật thể cần kết nối tới Claude API. Khi chạy offline (mở file trên máy), bạn cần dán API key của riêng mình vào đây.

Cách lấy API key
Vào console.anthropic.com, đăng ký / đăng nhập tài khoản (khác với tài khoản Claude.ai thường).
Vào mục Billing, thêm thẻ thanh toán & nạp một ít credit (API tính tiền theo lượng dùng — dựng vài cảnh rất rẻ).
Vào Settings → API Keys, bấm Create Key, đặt tên rồi copy ngay (key chỉ hiện một lần).
Quay lại đây, dán key vào ô trên rồi bấm Lưu. Key lưu trong trình duyệt máy bạn.

⚠ Key lưu trong trình duyệt máy bạn, không gửi đi đâu ngoài Anthropic. Đừng chia sẻ file đã lưu key.
ℹ Nếu mở file kiểu file:// (nhấp đúp) bằng Chrome, trình duyệt chặn lưu lâu dài — key vẫn dùng được trong phiên này, nhưng lần mở sau phải nhập lại. Muốn nhớ vĩnh viễn: dùng Firefox, hoặc chạy qua localhost (xem file hướng dẫn kèm theo).

Mẹo tăng độ chính xác
Khối thô khó nhận ra? Chọn khối → mục Texture 2D → dán ảnh tham chiếu thật lên khối (vd ảnh xe máy thật). Khối sẽ mang hình thật, AI hiểu ngay.
Đưa ảnh có nhãn cho GPT-Image/Nano Banana, gõ: "giữ nguyên bố cục và góc máy trong ảnh, chuyển thành [phong cách], các nhãn chỉ vật thể nào".
Muốn khóa góc tuyệt đối: dùng ảnh sạch làm input cho ControlNet (Depth/Canny) trên Replicate — góc giữ 100%.

Hướng dẫn & Phím tắt

✕
Quy trình cơ bản
Thêm chủ thể: bấm model ở cột trái (hoặc gõ ô tìm kiếm), hoặc dùng AI dàn cảnh / dựng từ ảnh bên phải.
Sắp đặt: chọn công cụ Di chuyển / Xoay / Tỉ lệ trên thanh giữa, rồi kéo vật thể trong cảnh.
Đặt máy quay: dùng chuột xoay quanh cảnh; chỉnh tiêu cự, khẩu độ, cao độ, góc máy nhanh ở cột phải.
Chụp shot: bấm nút Chụp shot — ảnh lưu vào danh sách, bấm để tải về làm tham chiếu storyboard.
✨ Storyboard: bấm nút Storyboard (cam) — xuất ảnh previz có nhãn từng khối (Việt+Anh) + prompt sẵn, để AI tạo ảnh (GPT-Image/Nano Banana) hiểu đúng góc & vật thể. Có nút "AI viết prompt điện ảnh" nếu đã nhập API key.
Lưu việc: tạo Project để app tự lưu offline; hoặc Xuất file .json để sao lưu.
Điều khiển chuột trong cảnh
Chuột trái kéoXoay camera quanh cảnh (chế độ Orbit) Lăn chuộtPhóng to / thu nhỏ Chuột phải kéoLia (pan) camera Bấm vật thểChọn để chỉnh sửa Shift + bấmChọn thêm nhiều vật (di chuyển/xoay cả nhóm). Cần ở chế độ Orbit. Kéo trục gizmoỞ Di chuyển / Xoay / Tỉ lệ, vật đang chọn hiện trục X Y Z: kéo mũi tên = dời theo 1 trục · ô vuông nhỏ = trong mặt phẳng 2 trục · vòng = xoay quanh trục · hộp = tỉ lệ. Kéo thân vật vẫn dời trên sàn như cũ. W/E/R + chuột phảiĐang ở Di chuyển / Xoay / Tỉ lệ vẫn lia (chuột phải/giữa kéo) và lăn zoom được. Ô Trên/Trước/PhảiChế độ 4 góc: lăn = zoom về con trỏ · chuột phải kéo = lia · bấm = chọn vật · kéo vật = dời/xoay/tỉ lệ trong mặt phẳng ô · nháy đúp = lấy tâm. Khung cam màu cam = tầm nhìn camera chụp.
Phím tắt
Nhiều màn hình (2–3 màn)
Nút Màn hình trên thanh trên cùng → Bố cục 2 màn hình (màn 2: màn hình máy quay) hoặc Bố cục 3 màn hình (màn 2: 4 góc nhìn · màn 3: máy quay). Chrome/Edge hỏi quyền "Quản lý cửa sổ trên tất cả màn hình" lần đầu — cho phép để app tự đặt cửa sổ lên đúng màn hình.
Cửa sổ phụ chạy trực tiếp cùng cảnh: chọn/kéo vật ở đâu cũng cập nhật mọi màn. Phím tắt (W/E/R/Q, Del, Ctrl+Z…) gõ ở cửa sổ phụ vẫn tác dụng lên app. Nút ⛶ trong cửa sổ = toàn màn hình, ⇄ = đổi nội dung (máy quay ⇄ 4 góc).
Trình duyệt chỉ cho mở 1 cửa sổ mỗi lần bấm: nếu báo chặn popup, bấm biểu tượng chặn trên thanh địa chỉ → Luôn cho phép, rồi bấm lại nút bố cục để mở cửa sổ còn lại.

⌨ Tùy chỉnh phím tắt

✕
Bấm vào phím đang gán để đổi · + để thêm phím (tối đa 3) · rê chuột lên phím rồi bấm ✕ để gỡ · ↺ về mặc định. Khi đang chờ: bấm tổ hợp mới (giữ Ctrl / Alt / Shift nếu muốn), Esc để huỷ. Phím đang thuộc thao tác khác sẽ tự chuyển sang. Lưu ngay trong trình duyệt này.
Cố định — không đổi được
Lùi một bước: đóng bảng → thoát ô nhập → bỏ chọn (và huỷ khi đang chờ bấm phím)
Esc
Giữ khi kéo trục gizmo / kéo trong ô 4 góc = bắt bước 0.25 m · 15° · 0.1×
Ctrl
Giữ khi kéo thân vật (Di chuyển) = nâng lên / hạ xuống
Alt
Giữ khi bấm vật (Orbit) = chọn thêm nhiều vật · giữ khi lăn chuột = zoom bước tinh
